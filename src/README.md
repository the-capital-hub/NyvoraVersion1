# NYVORA — WOW FRONTEND

Premium Indian legal-tech / luxury law-firm frontend.

## Included
- Redesigned premium green + champagne-gold UI
- Modern glass navbar with Practice Area mega-menu
- Contact link in desktop + mobile navigation
- Cinematic Hero
- Signature NYVORA legal journey
- Detailed public pages and linked detail pages
- Consultation flow
- NYVORA AI section
- Floating AI chatbot UI with local demo responses
- Framer Motion animations
- Responsive layouts
- HTTPS demo images

## Install
npm install
npm install react-router-dom framer-motion

## Run
npm run dev

## Production note
This is frontend-only. Chat responses are demo/local logic. Connect the chatbot to a secure backend and an approved legal knowledge source before production. Replace all demo contact information, images, biographies, claims and case examples with verified firm content.
